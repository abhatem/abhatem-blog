# Gemini Context

This file provides context for the Gemini AI assistant when working on this blog.

## Project Overview

*   **Generator:** Zola
*   **Theme:** Custom retro/terminal theme (zola.386 based)
*   **Deployment:** Netlify
*   **Content:** Tech blog posts in Markdown.

## Common Tasks

*   Create a new blog post: Manually create a new file, e.g., `content/posts/my-new-post.md`
*   Run the development server: `zola serve`
*   Build the site: `zola build`

## Content Conventions

*   **YouTube Videos:** Embed videos using the `youtube` shortcode: `{{ youtube(id="VIDEO_ID") }}`.
*   **Images:** Add images using standard Markdown `![alt text](image.jpg)`. Place the image file in the same folder as the post's `index.md`.
*   **Links:** Use standard Markdown links: `[link text](https://example.com)`.
